# Centro Físico Vital - Landing Page

Esta é a página oficial (landing page) do **Centro Físico Vital**, uma clínica especializada em Fisioterapia e Quiropraxia baseadas em evidências. O Método Vital une ciência, biomecânica e atendimento personalizado.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3 (Vanilla):** Estilização com design system próprio (variáveis de cor), CSS Grid e Flexbox. Layout totalmente responsivo.
- **JavaScript:** Scripts leves para interatividade.

## ⚙️ Estrutura do Projeto

- `index.html`: Arquivo principal contendo todo o conteúdo, seções da clínica, avaliações, ecossistema e FAQ.
- `style.css`: Estilização principal, contendo design responsivo e ajustes de layout (Mobile First e media queries).
- `script.js`: Comportamentos e interações da interface de usuário.

## 📱 Destaques do Projeto

- **Design Responsivo:** Adaptado e testado para celulares (Mobile), Tablets e Desktops garantindo a melhor experiência.
- **Layout Inteligente (Ecossistema):** Grade de serviços ajustável automaticamente (5 colunas no desktop, layout quebrado para tablet e coluna única no mobile) mantendo simetria de tamanhos.
- **Integração WhatsApp:** CTA flutuante e botões de agendamento que direcionam para o contato com mensagens pré-configuradas visando alta conversão.

## 🌐 Publicação

Projeto configurado para ser hospedado via GitHub Pages.
